# Delivery phases

- Phase 1 — two-folder monorepo, Maven and Vite workspaces, environment-driven ports
- Phase 2 — PostgreSQL/Flyway schema and bootstrap dealer
- Phase 3 — JPA domain, repositories, JWT and role-based security
- Phase 4 — services, REST APIs, scheduled reminders, LIC instalments, Excel reporting
- Phase 5 — shell, authentication, responsive navigation and shared design system
- Phase 6 — dealer dashboard, customers, policies, vehicles, reminders and reports
- Phase 7 — customer portal, Render/Vercel configuration and production env templates
